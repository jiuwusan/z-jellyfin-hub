# Hub 移动端布局验收

用户已确认：移动端避免横向拖动，导航入口换行，订阅信息以卡片完整展示，页头及长内容适应屏幕。

## 改动

不超过 960px 的视口使用三列导航网格，五个入口分两行；包含手机竖屏和较窄横屏。订阅表格在移动端显示为卡片，使用者和授权/策略占整行，版本与状态并排，底部保留完整详情按钮。数据及事件只维护一份，表头保留列语义，卡片用字段标签补充视觉上下文。页头按钮、长名称、地址、详情操作和弹窗允许换行。未用页面级横向裁剪隐藏内容。

大屏继续使用侧栏与原表格；本轮不改 API、鉴权、令牌、下发配置和发布流程，不涉及 Android/iOS 原生代码，也不修改 NAS 或其他服务配置。

## 浏览器验证

使用独立 localhost 服务和隔离浏览器页，数据全部虚构，不读取真实账号、订阅或服务器配置。通过实际 DOM 几何值检查页面、导航及列表内容宽度，并检查全部入口和字段存在。

旧实现 390px 下导航内容宽 538px、表格内容宽 511px，出现局部横向滚动；调整后内容宽度均等于对应容器宽度。

额外覆盖 320px 下的长使用者/授权名称、长地址、订阅详情和全部操作、四类模板页、播放策略弹窗、空列表及长错误提示。详情按钮仍能打开对应路由，模板导航可正常切换。已检查使用虚构数据的手机截图并在会话展示，不生成包含真实配置的截图。本轮为浏览器视口仿真，未宣称 iOS Safari 或全部真实手机浏览器均已验收。

前端 11 项测试、类型检查及生产构建通过，Go 完整测试和 vet 通过；Compose 外部网络 wk、8097 端口及 Go embed 的前端构建路径保持原设置。本机无 Docker CLI，未执行镜像构建或 Compose 启动。独立测试服务、浏览器页及临时程序在交付前关闭清理。验收期间未操作线上服务；NAS 需另行拉取已发布镜像更新。
