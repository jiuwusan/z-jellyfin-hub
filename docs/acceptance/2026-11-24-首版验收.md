# Hub 首版实施与验收

日期：2026-11-24。需求见 [技术方案](../requirements/技术方案.md)，接口见 [订阅协议](../api/订阅协议.md)，部署见 [Docker 与 Actions](../deployment/Docker与Actions.md)。

## 已实现范围

Hub：Go、Vue/TypeScript、SQLite；代理、服务、授权、画质模板；个人订阅草稿、预览发布、历史回滚、启停、令牌轮换和反馈查询。数据库凭据与版本快照加密，令牌摘要，管理员密码哈希，会话/CSRF/限流，初始化、备份和主密钥校验。模板引用保存草稿，发布明确应用到所选订阅，不自动批量发布。

Android 0.6.42（versionCode 56）：HTTPS 订阅、独立直连引导、ETag、Keystore 缓存、离线回退、验证成功后切换、播放期间延后换连接、后续取流使用新画质、停用后禁止新取流。设置页只输入链接并显示受管信息，保留字幕和音轨偏好，移除旧版手动配置入口与启动回退。新模块采用 SubscriptionController 完成原计划 ConfigurationApplier 职责。已有媒体/代理/字幕行为及之前未提交的页面、图片缓存改动保留。

iOS：本轮仅需求、协议和联调验收交接，未改 Swift 工程、未构建或安装 iOS。

## 待部署与验证

本机无 Docker 引擎、gh CLI 和 C 编译器；未执行 Docker build/Compose 运行、Linux race 测试或 Actions 发布。流程已配置在 Ubuntu Actions 中执行 `go test -race`、Compose 检查及双架构镜像发布。尚未提交或推送，因此不能宣称云端检查已通过或镜像已发布。

生产 HTTPS 域名、TLS 入口、Docker Hub secret 和 NAS 部署由后续实施确认。未改变现有 Jellyfin、mihomo、nginx、路由器或 Android 之外设备配置。临时 Hub 回环测试不等同于真实 HTTPS Hub → 手机完整联调；上线后需按客户端交接清单再验收一次。

第一版 Android 反馈上报 applied/pending；更多失败类别的自动上报保留为后续增强。令牌轮换/停用只影响守规客户端后续连接，离线缓存无法即时撤权。主密钥与数据库要分别备份。

## 首次引导与无固定地址补充验收

已取消 HUB_PUBLIC_URL 和 Compose environment，使用独立 data/secrets 卷。首次自动生成主密钥和一次性码，网页引导设置管理员，完成后码及摘要被移除；重启不重建管理员或密钥。后台无域名/IP/端口/HTTP(S) 白名单，写操作仍校验 Origin/Host 与 CSRF；不自动设置 HSTS。Android HTTPS 订阅规则未改。

新增 Go 用例验证任意域名、IPv4/IPv6、端口、HTTP/HTTPS、路径前缀、跨站/缺失 Origin 或 CSRF 拒绝、引导身份/重复/并发初始化、密钥与码重启稳定、旧库缺密钥拒绝。前端 Node 测试验证当前地址生成链接与前缀保留。Go 测试/vet、前端测试/构建及无 CGO Linux amd64/arm64 构建通过。独立回环浏览器验证 /hub/ 首次引导、登录、生成相对链接对应完整 URL，以及更换 localhost 主机名后仍可登录；无真实服务或账号参与。

Compose 与 Actions 仅静态核验，无 Docker 环境，未宣称容器运行、镜像发布或 NAS 部署。本轮未修改 Android 代码及既有服务配置。

混合 HTTP/HTTPS 访问已补充独立 Cookie 命名与退出清理回归，防止 HTTP 登录被既有 Secure Cookie 阻挡；最终只读评审未发现剩余 P1/P2。

## 无 ID 令牌订阅与恢复（0.6.43 / schema v2）

配置/反馈使用固定 subscription 路径，令牌摘要唯一定位；管理端新建/设置可指定原令牌，随机生成仍可用。服务实例元数据持久化，ETag 包含实例/内部订阅/版本；重建新库产生新实例。Android 新来源重新验证成功后允许版本 1，同来源禁止回退及同版本改内容（含换 URL 情况）。已有受信任的 v1 缓存可自动转换旧链接，无需重新输入；网络只接收 v2。

新增 Go HTTP 双数据库测试覆盖原令牌恢复到不同内部 ID/实例且不误回 304，手动创建/修改/重复绑定/非法 CRLF 保留原绑定、令牌查询不回显、旧令牌失效、停用优先于 ETag、固定反馈路径。存储测试覆盖实例重启/备份稳定和新库变化。前端单元测试、类型检查与构建通过；回环浏览器已真操作指定令牌创建、发布、修改及恢复原令牌，固定链接路径正确、旧令牌 401、恢复 200。

荣耀 0.6.43 运行 subscription、subscription-controller、subscription-lifecycle 三组受控检查通过，涵盖较低版本恢复、重新鉴权失败保留缓存、已阻止连接设备自动恢复、旧缓存迁移、跨链接同来源防回退和既有播放会话边界。测试使用虚构配置和隔离 Keystore 范围，不改真实代理/授权；本轮未进行真实 HTTPS Hub 到手机的生产联调或新版本视频硬解验收，上一版硬解结果仅为历史记录。Docker/NAS 部署和镜像发布仍未执行。

恢复时取得的新 JellyfinApi 即使连接字段未变，也会在安全时机替换旧对象；新增荣耀红绿回归验证播放期间延迟应用，避免新登录会话被丢弃。最终只读评审未发现剩余明确 P1/P2。
