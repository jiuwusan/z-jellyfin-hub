# z-jellyfin-hub 开发规范

## 工程

Go 1.27 标准库 HTTP，SQLite 使用无 CGO 驱动；Vue 3、TypeScript 与 Vite 构建管理后台并嵌入 Go。结构分为 domain、secret、storage、service、httpapi 与 cmd/hub。前端位于 web。

配置是完整版本快照，草稿不能直接影响已发布内容。个人订阅相互隔离；共享模板变更通过预览和显式发布应用。密文绑定记录/字段上下文；令牌只存摘要；管理登录使用密码哈希、会话 Cookie、CSRF 和限流。

## 部署

Compose 使用外部网络 wk、命名数据卷和独立只读 secret 文件；运行用户非 root，单进程单实例。仅暴露内部 8080/TCP，HTTPS 由入口代理提供。首次初始化生成随机密钥与管理员密码文件，不输出秘密。

Actions 的 PR 只检查测试；master push 或手动触发在检查通过后推送 jiuwusan/z-jellyfin-hub 镜像，包含 latest 与提交 SHA 标识。需要仓库 secret DOCKERHUB_TOKEN。不增加远程 SSH 部署。

## 验证与提交

使用临时数据库和临时密钥进行测试，禁止测试依赖个人服务。前端类型检查与构建、go test ./...、go vet ./... 必须通过。当前分支工作，不自动提交或推送；提交格式为类型加中文摘要。

跨项目协议样例、需求和交接文件保留相对引用，复制后核对数量及 SHA-256。Android 实施订阅接入，iOS 仅归档交接，不宣称已实现。
