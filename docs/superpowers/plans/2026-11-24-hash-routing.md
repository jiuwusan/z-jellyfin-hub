# Hash 路由与任意反代前缀

用户已明确要求，当前 master 实施，不提交/推送，不改现有 NAS/nginx 配置。保留既有引导、CSRF、令牌和发布行为。

- 使用 Vue Router createWebHashHistory，无固定部署 base。物理路径确定资源/API/订阅链接前缀，hash 仅用于登录、初始化、管理页签和订阅详情导航。
- 根 App 只承载 RouterView，现有管理界面复用为 HubConsole，路由切换保留会话与已加载数据；认证后回到原目标，前进/后退、刷新与详情直达可用。异步详情响应按导航代次隔离，离开时清理临时秘密输入。
- 不将 hash 页路径拼到 API/静态资源/订阅链接；原链接 #TOKEN 与管理页面 #/route 分开。不写死 /hub/，支持任意多级前缀；反代保留或剥离前缀都可。
- 外部 nginx 保留 Host（含端口），API 保留 Authorization；提供可替换前缀的 proxy_pass 两种示例，不要求 history try_files。现有 8097、TZ、wk、独立卷配置不变。
