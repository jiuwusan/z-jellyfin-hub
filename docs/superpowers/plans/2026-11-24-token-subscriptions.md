# 令牌唯一订阅与灾后恢复实施计划

用户已确认，当前分支执行，不提交/推送，不改既有服务配置。Hub 与 Android 同步；iOS 本轮仅协议交接。

## 设计

- 对外配置地址固定 api/v1/subscription/config#TOKEN，反馈为 api/v1/subscription/feedback。数据库内部订阅 ID 保留，但不进入链接。Bearer 中的 TOKEN 摘要唯一定位订阅，停用/鉴权先于 ETag。
- 管理新建订阅时令牌可留空随机生成，也可指定原 43 字符规范 Base64URL 令牌；已有订阅支持设置指定令牌或随机轮换。不同订阅不可绑定同一令牌；只存摘要，错误与查询不回显秘密。
- 配置 schemaVersion=2，新增 serverInstanceId。数据库首次生成随机实例标识并持久化；备份/重启保留，数据库重建产生新标识。客户端以实例标识+内部订阅标识划定版本序列：同序列禁止倒退/同版本变内容，新序列必须重新验证代理和 Jellyfin，成功后接受从 1 开始的版本。
- API ETag 包含实例、订阅和版本，防止灾后误用 304。回滚仍发布同实例更高版本，不把版本倒退当恢复。
- Android 新导入使用无 ID 链接。已有加密缓存可在本地自动转换旧链接/已验证配置，再首次联机获取 v2；不恢复旧手动配置入口。网络仅接受 v2，保留 HTTPS、Keystore、直连、离线缓存、播放中延迟换连接和 CSRF 等既有边界。
- 灾后管理员在同一 HTTPS 入口重建模板、新建订阅并填原令牌、发布；设备保持原令牌链接，自动同步恢复。原链接/令牌需独立备份，主密钥丢失不能解密旧库；本功能恢复的是新建配置的绑定。
