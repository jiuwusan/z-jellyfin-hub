# 持续复制订阅链接

用户已确认：管理员可随时复制订阅链接；旧订阅补录原链接或令牌后可复制，设备原链接不变。

1. 保留 SHA-256 摘要鉴权，新增可空 `token_cipher` 列，使用现有主密钥 AES-GCM，AAD 绑定订阅 ID。已有数据库增量迁移，旧摘要不变。
2. 创建、设置及轮换令牌同时原子保存摘要和密文；普通草稿编辑保留密文。普通列表只暴露 `hasSavedToken`，不返回令牌或密文。
3. 新增管理员 POST `/subscriptions/{id}/link` 按需返回相对链接，POST `/subscriptions/{id}/link/restore` 补录匹配旧摘要的令牌；两者均要求会话和 CSRF，不缓存。补录不能轮换令牌或改变配置版本。
4. 详情页常驻复制按钮。旧订阅引导补录完整链接或令牌，页面跳转及退出清除临时值。复制兼容 HTTPS Clipboard API、HTTP 备用复制及手动复制提示，继续保留任意部署前缀。
5. 使用隔离数据库和随机测试令牌覆盖迁移、重启、密文篡改/跨记录替换、轮换、补录错误、普通响应脱敏及鉴权；执行 Go 测试/vet、前端测试/类型检查/构建，核对 Compose/Dockerfile。

仅 Hub 管理功能与存储变化，手机订阅协议和 Android/iOS 客户端无需修改。本轮不部署、不修改现有服务配置，不自动提交或推送。
