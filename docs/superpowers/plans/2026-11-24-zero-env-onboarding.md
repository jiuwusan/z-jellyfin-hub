用户已采纳：Compose environment 仅设置 TZ=Asia/Shanghai；首次创建管理员；HUB_PUBLIC_URL 取消；后台访问不限制域名、IP、端口或 HTTP/HTTPS。当前分支实施，不自动提交/推送，不改既有服务配置。

## 边界与设计

- 后台 API 与静态资源按相对部署路径请求；服务只返回订阅相对路径，浏览器按当前访问地址拼接，不采信转发头生成公开链接。支持根路径和反代路径前缀。
- 不配置地址白名单；写操作仍校验 Origin 与本次请求 Host 同源、CSRF Token、SameSite Cookie。HTTPS 浏览器使用 Secure Cookie；允许 HTTP 管理，但手机订阅 HTTPS 规则保持不变。
- 首次启动自动生成随机数据库密钥到独立持久化 secrets 卷；已有库缺密钥拒绝启动。初始化码同卷保存，通过容器命令查看，不写日志。
- 引导仅设置管理员账号/密码，不填公网地址。初始化码验证后事务创建账号；一次完成后关闭初始化入口，重启不重建账号或密钥。
- 已部署数据库继续使用原密钥文件可选路径覆盖，不重置凭据。Docker 默认两个独立卷，wk 网络；Actions 继续仅检查和发布镜像。
